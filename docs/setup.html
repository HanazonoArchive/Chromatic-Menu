Connect your shop to the dashboard

Supabase stores the heartbeats your PCs send and the games customers request. You create the project once, point each PC at it, then open the dashboard from any browser.

1

Create a Supabase project

2 min
  1. Go to supabase.com and sign up for a free account.
  2. Click New project. Name it (for example my-shop) and set a database password.
  3. Choose the region closest to the shop. For the Philippines: Southeast Asia (Singapore).
  4. Wait a minute or two while the project is created.
2

Run the database schema

1 min
  1. Open SQL Editor›New query.
  2. Click Copy below, paste everything into the editor, and click Run.
  3. You should see Success.
schema.sql 
Loading schema...
Safe to run again.It never deletes your data. It creates the tables, the security rules (the public key can only add data, never read it), the functions the dashboard uses, and two scheduled jobs: an hourly daily summary, and removal of raw heartbeats older than 90 days.
3

Turn off public sign-ups

30 sec

Only accounts you create yourself should be able to open the dashboard.

  1. Open Authentication›Sign In / Providers.
  2. Turn off Allow new users to sign up and save.
4

Create your dashboard login

1 min
  1. Open Authentication›Users›Add user›Create new user.
  2. Enter your email and a strong password, and tick Auto Confirm User.
  3. Repeat for anyone else who should see the dashboard.
5

Copy the Project URL and anon key

30 sec

Open Project Settings›API (on newer projects: Data API and API Keys).

Project URLhttps://abcdefgh.supabase.co
anon / public keyA long text starting with eyJ

You need both in step 6 and step 7.

6

Connect each PC

2 min per PC

Boot the PC Thawed if Deep Freeze is installed. Chromatic Menu has no built-in project, so nothing is sent until you do this.

A PC sends heartbeats only when all three are true:

1. Start with WindowsSettings › General
2. Enable telemetrySettings › Telemetry (on by default)
3. URL and anon key setSettings › Telemetry, or the DataTool

Option A: DataTool (fastest)

  1. Run tools\ChromaticMenu-DataTool.bat and choose [2] Set up Supabase.
  2. Press Enter to use the URL and key preset at the top of the .bat, or type your own.

Option B: in Chromatic Menu

  1. Open Settings›Telemetry (admin password), paste the URL and key, click Save, then Test connection.
Check it worked.Settings › Telemetry shows Service: Running and no warnings. The Request a Game button appears in Technical Tools. Then freeze the PC again.
7

Open the dashboard

1 min
  1. Open the dashboard and paste the same Project URL and anon key.
  2. Sign in with the account from step 4.

You stay signed in on that browser until you log out, even after closing it. PCs appear within a minute of sending their first heartbeat.

Troubleshooting

No PCs appear in the dashboard
Check the three conditions in step 6 on that PC. Settings › Telemetry shows the service status and any warning. The service log is at C:\Program Files\Chromatic Menu\data\logs\telemetry.log.
"The database is not set up yet"
Step 2 was not run, or it ran on a different project than the URL you entered.
Sign in fails
The user must exist in Authentication › Users and be confirmed (tick Auto Confirm User when creating it).
Request a Game is missing or fails
The button only shows when telemetry is on and a URL and key are set. Each PC can send one request every 5 minutes; titles are limited to 100 characters and details to 500.
Check that your data is private
This uses the public key to try to read heartbeats. It must return [] or a permission error, never data.
Terminal 
curl "https://YOUR-PROJECT.supabase.co/rest/v1/heartbeats?select=*&limit=1" \
  -H "apikey: YOUR-ANON-KEY" \
  -H "Authorization: Bearer YOUR-ANON-KEY"
